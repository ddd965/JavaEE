使用 Cursor 开发“电商订单管理系统”时所需的所有代码文件清单（按开发顺序排列） 
> 注：仅列出文件名与职责，不包含具体代码实现。
## 一、项目功能总结（电商订单管理系统）
### 核心业务模块（4个，满足增、删、改、条件查询、分页查询）
| 模块 | 功能说明 | 包含操作 |
|------|----------|----------|
| 商品管理 | 维护商品信息 | 增加商品、删除商品、修改商品、按名称/分类/价格区间条件查询、分页查询 |
| 订单管理 | 用户下单、订单状态流转 | 创建订单、取消订单、修改订单状态、按订单号/状态/时间范围查询、分页查询 |
| 用户管理 | 用户注册及信息维护 | 新增用户、删除用户、修改用户信息、按用户名/手机号/邮箱条件查询、分页查询 |
| 购物车管理 | 暂存用户选购的商品 | 添加商品到购物车、删除购物车项、修改数量、清空购物车、查询当前用户购物车列表（分页） |
### 满足实验要求的其他关键特性
- 多表关联查询（MyBatis）  
  - 一对一：查询用户及其扩展信息（`user` + `user_profile`）  
  - 一对多：查询用户及其所有订单（`user` + `order`）  
  - 多对多：查询订单及其包含的所有商品（`order` ↔ `product` 通过 `order_item`）
- Redis 缓存应用  
  - 商品热点数据缓存（商品详情、商品列表分页）  
  - 用户登录令牌（JWT + Redis 黑名单/白名单）  
  - 避免缓存穿透/击穿（布隆过滤器或空值缓存）
- Service 层复杂逻辑（至少包含两项）  
  - 声明式事务管理（下单时扣减库存、创建订单、清空购物车）  
  - 业务校验（库存是否充足、订单状态流转合法性、用户权限）  
  - VO 封装（返回给前端的对象不是 Entity）  
  - 缓存逻辑（先查 Redis，未命中再查 DB 并回写）

## 二、按开发顺序列出所有需要的代码文件
> 开发顺序遵循：环境配置 → 实体层(Entity) → 数据访问层(Mapper/XML) → 业务层(Service) → 控制层(Controller) → 视图对象(VO/Util) → 前端页面与组件 → 测试与配置完善
### 1. 后端项目结构与配置文件
```
src/main/java/com.example.javaee_ecomorder /
│
├── EcomApplication.java               # SpringBoot 启动类
│
└── config/                            # 配置类
    ├── RedisConfig.java               # Redis 配置（序列化、连接工厂）
    ├── WebMvcConfig.java              # 跨域配置、拦截器注册
    ├── MybatisPlusConfig.java         # MyBatis 分页插件配置
    └── SwaggerConfig.java             # API 文档（可选，便于测试）
```
```
src/main/resources/
│
├── application. properties              # 主配置文件（数据库、Redis、日志）
├── application-dev.yml                # 开发环境配置
└── db/                                # 数据库脚本
    └── data.sql                       # 初始测试数据
```
### 2. 实体层（Entity） – 对应数据库表
```
src/main/java/com.example.javaee_ecomorder/entity/
│
├── User.java                          # 用户表
├── UserProfile.java                   # 用户扩展信息表（一对一）
├── Product.java                       # 商品表
├── Order.java                         # 订单表
└── OrderItem.java                     # 订单商品明细表（多对多关联表）
└── Cart.java
```
### 3. Mapper 层（数据访问）
```
src/main/java/com.example.javaee_ecomorder/mapper/
│
├── UserMapper.java                    # 用户表 CRUD + 一对一关联查询
├── UserProfileMapper.java             # 扩展信息表
├── ProductMapper.java                 # 商品表 CRUD + 条件分页
├── OrderMapper.java                   # 订单表 + 一对多（用户→订单）
├── OrderItemMapper.java               # 订单明细 + 多对多（订单→商品）
└── CartMapper.java                    # 购物车（可单独设计购物车表，或使用临时表/Redis）
```
```
src/main/resources/mapper/
│
├── UserMapper.xml                     # SQL：一对一（user left join user_profile）
├── UserProfileMapper.xml
├── ProductMapper.xml                  # 动态 SQL 条件查询、分页
├── OrderMapper.xml                    # 一对多（user_id 查订单集合）
├── OrderItemMapper.xml                # 多对多（订单→商品，连 product 表）
└── CartMapper.xml                     # 购物车 SQL（如设计了购物车表）
```
